# Termux for Windows

**Termux for Windows** is a Linux terminal on PC. Windows 11 / 10 zip. WSA optional. Python, Kali, Ubuntu, X11, commands list. Free download - no Play Store, no phone.

## Getting Started
1. Download v1.2.0.
2. Extract `termux-windows.zip`.
3. Run `Termux.exe`.
4. `pkg update && pkg upgrade`
5. Optional: `pkg install python`

## FAQ

**What is it?**
A Linux environment on Windows. Phone not required.

**WSA?**
Optional. Win11 can run the Android layer through WSA. The zip also runs as a desktop shell.

**APK?**
This release is the Windows build. Filename is `termux-windows.zip`.

## Requirements
Windows 10/11 (64-bit). WSA optional on 22H2+.
